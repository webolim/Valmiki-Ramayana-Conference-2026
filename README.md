# WEBOLIM Sri Rama Navami Utsavam - 2026

This is the digital schedule and invite website for the Sri Ramayana Satram & Valmiki Ramayana Conference 2026.

## Project Structure

- `index.html`: Main landing page with the schedule and event details.
- `print.html`: Optimized print layout for the schedule.
- `schedule.json`: Data source for events and speakers.
- `index.css`: Main stylesheet (Tailwind CSS v4).
- `print.css`: Print-specific stylesheet.

## Development

This project uses [Vite](https://vitejs.dev/) and [Tailwind CSS](https://tailwindcss.com/).

### Prerequisites

- Node.js installed on your machine.

### Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Deployment

The `dist` folder created by `npm run build` is ready to be deployed to any static hosting service (GitHub Pages, Vercel, Netlify, etc.).
